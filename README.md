# AppScreenMark：在线制作 App Store / Google Play 应用截图

做了一款面向独立开发者的应用商店截图编辑器 **AppScreenMark**，可以直接在浏览器中完成截图排版、设备样机展示和图片导出，方便准备应用上架素材。

**完全免年费，自由定制。** 从模板到文字、图片和背景，都可以按应用的风格调整。

## 主要功能

- **多套设计模板**：选择模板后替换截图、修改文案，快速完成排版。
- **可视化编辑**：支持文字、图片、背景、设备框及元素位置、大小和旋转调整。
- **多平台与多尺寸**：适配 App Store 和 Google Play 截图制作。
- **多语言截图**：管理不同语言的截图内容，按平台、分辨率和语言打包导出 PNG。
- **本地处理与保存**：图片编辑和导出在浏览器本地完成，支持草稿自动保存、撤销和重做。
